Exporte der Online-Labeler hier ablegen (`beeflight_<name>_<datum>.jsonl`, eine Datei pro Person reicht; bei
mehreren Dateien derselben Person zählt pro Bahn das neueste Label). Am einfachsten über **Exporte hochladen**
auf der Startseite des lokalen Labelers, der die Dateien vorher prüft. Danach `uv run beeflight-vote`.
